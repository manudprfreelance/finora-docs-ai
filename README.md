# Finora Docs AI

AI-powered document automation platform for financial services.

Finora Docs AI combines agentic AI, deterministic business rules and workflow orchestration to automate complex document requests securely and traceably.

## Project status

🚧 Under active development.

## Core stack

- Next.js
- TypeScript
- FastAPI
- Python
- PostgreSQL
- n8n
- Docker
- OpenAI

## Architecture

The platform follows a hybrid architecture in which AI interprets user intent while deterministic services remain responsible for authorization, business rules and transactional truth.

> AI interprets language. Deterministic systems establish truth.
